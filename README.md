# Pharmacy Sales & Inventory Analysis 🔬📊

## Overview
Interactive dashboard analyzing pharmacy sales trends, inventory turnover, and profitability metrics using Excel and Power BI. This project demonstrates the application of data analytics to optimize pharmaceutical operations and improve business decision-making.

![Dashboard Preview](placeholder-screenshot.png)

## Key Insights Discovered

- **Sales Trends**: Identified peak sales periods and seasonal purchasing patterns
- **Inventory Optimization**: Tracked medication stock levels to reduce waste and prevent shortages
- **Product Performance**: Ranked top-selling medication categories by revenue and volume
- **Profitability Analysis**: Analyzed margin variations across different product lines
- **Customer Behavior**: Detected repeat purchase patterns and customer segmentation

## Technical Implementation

### Tools Used
| Category | Tools |
|----------|-------|
| Data Processing | Microsoft Excel 365, Python (pandas) |
| Visualization | Power BI Desktop, Matplotlib |
| Querying | SQL (practice datasets) |
| Documentation | Markdown, Jupyter Notebooks |

### Analysis Process
1. **Data Collection**: Transaction records and inventory logs from simulated pharmacy operations
2. **Data Cleaning**: Handled missing values, standardized date formats, validated numerical ranges
3. **Exploratory Analysis**: Created pivot tables, calculated key performance metrics
4. **Visualization**: Built interactive dashboards with drill-down and filtering capabilities
5. **Business Recommendations**: Generated actionable insights for inventory management

## Key Metrics Analyzed

| Metric | Description | Business Impact |
|--------|-------------|-----------------|
| Sales Growth Rate | Month-over-month revenue change | Track business health |
| Inventory Turnover | How quickly stock sells out | Optimize cash flow |
| Stockout Rate | Percentage of missed sales due to shortages | Improve customer satisfaction |
| Profit Margin | Revenue minus cost per category | Identify high-value products |
| Customer Retention | Repeat purchase frequency | Measure loyalty |

## Challenges Overcome

- **Data Quality Issues**: Implemented validation rules to catch inconsistencies
- **Privacy Concerns**: Anonymized customer information while preserving analytical value
- **Performance Optimization**: Reduced dashboard load time through efficient data modeling

## Lessons Learned

> "Healthcare data requires extra attention to privacy and compliance standards."

- Data quality preparation takes 80% of analysis time
- Business context matters more than technical complexity
- Clear storytelling with data drives better decisions than complex models
